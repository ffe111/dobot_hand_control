# Dobot Hand Control

[English](README.md) | ภาษาไทย

ต้นแบบหุ่นยนต์บน Raspberry Pi ที่แปลงท่ามือจากเว็บแคมเป็นการเคลื่อนไหวของแขน Dobot โดยใช้ MediaPipe หาแลนด์มาร์กมือ OpenCV รับภาพจากกล้อง และ PyDobot ส่งคำสั่งผ่านพอร์ตอนุกรม

## เริ่มจากไฟล์ไหน

| ไฟล์ | หน้าที่ |
| --- | --- |
| [`track.py`](track.py) | รับภาพจากกล้องและแปลงท่ามือเป็นคำสั่งเคลื่อนไหว |
| [`dobot.py`](dobot.py) | เชื่อมต่อพอร์ตอนุกรมและแสดงเมนูควบคุมด้วยตนเอง |
| [`requirement.txt`](requirement.txt) | ไลบรารี Python ที่ใช้ |

โค้ดมุ่งใช้กับ Linux ที่มีเว็บแคมและแขน Dobot รุ่นที่เข้ากันได้ เชื่อมต่อผ่านพอร์ตอนุกรม ใช้ Python 3.10 ขึ้นไป (เมนูใช้ `match`) และติดตั้งไลบรารีใน virtual environment ด้วย `python -m pip install -r requirement.txt` ตรวจค่า `serial_port` ใน `dobot.py` ให้ตรงกับเครื่อง เมนูควบคุมรันด้วย `python dobot.py` ส่วนโหมดเว็บแคมรันด้วย `python track.py`

## ข้อควรระวังในการใช้ฮาร์ดแวร์

ทันทีที่เชื่อมต่อ โปรแกรมจะสั่งให้แขนขยับ และท่ามือที่ถูกตรวจพบบ่อยอาจส่งคำสั่งมากเกินไป ก่อนทดลองทั้งสองโหมด ให้เคลียร์พื้นที่ ไม่ให้คนอยู่ในระยะเอื้อมของแขน และตรวจว่าสามารถหยุดการเคลื่อนไหวได้ ต้นแบบนี้ไม่ได้ผ่านการรับรองความปลอดภัย ยินดีรับข้อเสนอที่ช่วยให้การรับท่ามือคาดเดาได้ดีขึ้น เช่น ลดการส่งคำสั่งซ้ำ
